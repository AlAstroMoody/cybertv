# Cyber TV

Киберпанк IPTV-плеер: Vue 3, canvas-оверлей и HLS-потоки из M3U-плейлиста. PWA в полноэкранном ландшафте.

## Запуск

Нужен Node `^22.18.0` или `>=24.12.0`.

```bash
npm install
npm run dev
```

Сборка и превью:

```bash
npm run build
npm run preview
```

Превью и dev — с префиксом `/cybertv/` (как на GitHub Pages).

## Деплой

Одна команда: сборка и публикация ветки `gh-pages`, без `dist` в `main`.

```bash
npm run deploy
```

Сайт: https://alastromoody.github.io/cybertv/

Первый раз в репозитории: **Settings → Pages → Deploy from a branch → `gh-pages` / `/ (root)`**.

## Управление

Пульт / клавиатура:

| Клавиша | Действие |
|---|---|
| Enter | дальше / выбрать / эфир |
| ↑ ↓ ← → | категории и список каналов |
| CH+ / CH− | следующий / предыдущий эфир |
| Esc / Backspace | назад (в фуллскрине — сначала выход) |
| F / зелёная | полный экран |

Экраны: загрузка → приветствие → категории → плеер.

## Стек

Vue 3, TypeScript, Vite, hls.js, vite-plugin-pwa.

## Источники и право

В этом репозитории **нет видеофайлов**. Плеер только открывает ссылки на потоки из M3U.

Гостевой контур берёт общедоступный плейлист [iptv-org](https://github.com/iptv-org/iptv):

`https://iptv-org.github.io/iptv/languages/rus.m3u`

Каталог собирает пользовательские ссылки на стримы, которые, по оценке авторов, правообладатели сами выложили в открытый доступ. Ссылка на поток — не копия произведения: контент отдаёт тот хост, куда ведёт URL. Претензии по конкретному эфиру — к хостеру потока, не к составителю плейлиста и не к этому плееру.

Позиция источника целиком: [Legal в iptv-org/iptv](https://github.com/iptv-org/iptv#legal).
